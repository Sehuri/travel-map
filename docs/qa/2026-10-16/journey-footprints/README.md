# 旅程足迹：国内省级、海外国家（2026-10-16）

下述为本地实现与提交前验收记录；验收后用户另行授权更新项目 README 并推送 GitHub。原有旅行、照片、评分和后台数据没有修改。

## 变更

- 地图按钮由“省级足迹”更名“旅程足迹”；保留内部 `province` 视图标识，兼容既有视图切换逻辑。
- 中国按省级地区填色，保留中国细节的市域填色及全球视图。
- 海外城市按国家去重：日本、新加坡、印度尼西亚整国点亮，不再加载日本四都道府县边界；旧素材保留。
- 使用现有高德 SDK 的 World 国家面图层和中国 Country depth:1 省级图层，不引入手绘边界或外部 GeoJSON。接口参考：[高德简易行政区图官方说明](https://lbs.amap.com/api/javascript-api-v2/guide/layers/districtlayer)。国家 SOC、中文名或英文名统一匹配；没有国家信息的记录不会误点亮。
- 图例分别统计中国省级地区与海外国家。当前完整记录为 19 个中国省级地区、3 个海外国家；不把中国整体额外涂满，也不把日本四座城市重复算作四个国家。
- 年份、地区、搜索和评分仍共用现有筛选结果；愿望模式和其他地图视图隐藏国家填色；城市标记、详情和全屏入口保持可用。
- 更新首页脚本版本，避免浏览器继续使用旧填色逻辑。

- `node --check assets/app.js`、`node --check assets/admin-region-engine.js`、`git diff --check` 通过。
- 单元覆盖中国同省去重、外国 admin1 忽略、印尼别名合并、国家代码匹配、未来其他国家、空数据和年份过滤。
- 浏览器回归覆盖三国填色/未到访国家透明、中国仍按省、筛选新加坡后日本/印尼取消填色、国家面点击城市清单、切回中国细节隐藏国家图层、日本旧边界零请求；其他功能完整回归。

## 边界

- 填色按地图 SDK 提供的国家面显示，小岛简化程度及边界署名随原 SDK；自动取景仍依据当前可见城市，完整国家可能需要缩放/平移查看。
- 真实预览有 Supabase 提示多个 GoTrueClient 实例的现有警告，未出现地图运行错误；本轮没有改动认证客户端或后端设置。
