- 用户提供的两张文件均为正常 JPEG，2562×1442，分别为 796351 / 614274 字节；Sharp 完整解码成功。
- 独立 Chrome 验证两张图片的 `Image.decode()`、`createImageBitmap()`、480 / 960 / 1600px WebP 编码均成功，不是 15 MB 上限或 HEIC 误识别。

## 修改

- 私有媒体改用现有 Supabase SDK `storage.download()`，与上传使用相同的公开项目 Key 和登录身份。照片元信息和存储对象仍分别经过原有父手记 RLS，不生成公开地址或签名 URL。
- 手记服务的网络请求禁止缓存，撤下公开后的新读取按当前权限执行。没有修改数据库、存储桶、策略、密钥或线上函数。
- 已上传但读取失败与上传失败分别提示；编辑队列、阅读封面和查看器提供重新加载。重试读取不创建媒体、不重复上传。
- 公开相册缩略图/阅读封面继续使用现有预览回退工具，缺失预览可读取原图。
- 三个手记页面的相关脚本和样式版本更新至 `20261111.1`。
