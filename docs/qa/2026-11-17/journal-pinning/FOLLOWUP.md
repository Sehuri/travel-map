# 手记置顶补充测试

测试日期：2026-11-17。代码候选提交 `02a9585ad4f376928156410c5a4f2c0493436c6d`；补充测试在隔离副本上进行，未修改产品代码。用户表示已完成线上数据库迁移。

## 结果

- 临时 PGlite：除原有权限、幂等和撤销测试外，补充通过站主不能管理其他账号归属记录；保存拟私人修订保持当前公开置顶；继续公开发布保留原置顶时间；撤下操作回滚后置顶仍在；归档清理、恢复再公开不自动恢复置顶；正式发布为私人清理置顶。
- 隔离浏览器：模拟服务器完成置顶后响应丢失，界面通过读取操作标识确认成功，检查只发送一次置顶写入。已有权限失败、游客与私人草稿、撤销等手记浏览器回归通过。
- `npm test`：102 项单元测试及 10 组浏览器回归通过。测试使用本机 Chrome、PGlite 和隔离 SDK/存储；补充用例已保存到 `tests/journal-pinning-db.test.cjs` 和 `tests/journals-browser.cjs`。
- 线上匿名只读查询 `journal_public_entries` 的 `pinned_at` 字段返回 HTTP 200。这确认公开投影提供该字段，不证明迁移全部对象均正确、站主 RPC 可用或真实写权限正确。

## 仍未验证

真实多连接行锁及并发、网络超时到期和延迟响应的全部竞态、多条记录与全部筛选排序组合、照片重排请求、完整键盘/焦点和位置恢复、真实站主写入、登录非主人访问，以及部署后的线上功能尚未完整验证。本机未发现本地 PostgreSQL 服务端可执行程序；PGlite 单连接的顺序冲突测试不代表真实多连接并发。未对生产执行测试性置顶、撤销或修改真实数据；未合并 main 或发布。
