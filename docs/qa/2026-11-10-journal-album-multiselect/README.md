# 公开相册多选

本轮将单张点击即添加改为：勾选多张、查看已选数量，再统一添加到草稿。照片列表单独滚动，筛选、关闭和批量添加按钮始终可见；手机两列。已添加照片带对勾及“已添加”文字，不能重复勾选；未提交选择可清空或直接关闭。

## 实际验证

- 93 项单元测试通过。
- 完整手记浏览器流程通过，使用真实临时 PostgreSQL/RLS 与隔离 SDK/存储适配器，没有写入生产手记。
- 勾选/取消不关闭相册，不写入媒体；切换城市筛选保留勾选；Space 键可切换选择；Esc 关闭后焦点返回入口。
- 一次确认添加多张；已有照片不可重复添加；网络失败保留全部勾选，引用已创建但草稿保存失败时重试复用引用，原照片队列不变。
- 批量部分失败时，成功项保存、失败项仍勾选；再次提交仅添加剩余项，没有重复引用。
- 99 张待上传照片时只能再选择一张相册照片，不突破总计 100 张的限制。
- 390px 手机、1440px 桌面多选截图已实际查看，手机添加按钮在可见区域内、无横向溢出。原流程的 768/1024px 列表检查也通过。
- 脚本语法与 `git diff --check` 通过。数据库、权限和存储配置未改动。
