## 新模块覆盖

1. 新建默认草稿+仅自己，仅填地点名保存；补全地点位置时 ID 不变。数据库拒绝静默改写已共享/已发布地点。
2. 不关联城市的地点可发布；同一地点再写一篇得到不同手记 ID，地点计数仍为 1。
3. 日期/评分可空、未知日期/未评分文字、无照片占位、无关联旅程与无结果状态。
4. 未保存预览不改写数据库；发布确认、公开快照、私有修订、更新发布、撤下公开、归档/恢复。
5. 匿名与登录非主人在实际 SQL 角色下读不到私有条目、草稿、旧版本、仅私有地点或新修订媒体；直接写表和未授权 RPC 被拒绝。
6. 当前发布快照切换前，公开旧版保持可见；撤下公开后对象读取策略拒绝后续请求。
7. 单张上传失败后保留其他成功项并单独重试；从现有公开相册引用；前移/后移及边界按钮、设封面。
8. 搜索、类型过滤、清除、结果篇数/地点数、详情返回保留筛选与滚动位置。
9. 查看器 Esc、关闭后焦点回到打开按钮；有未保存输入离开时触发 beforeunload 提醒。
10. 390/768/1024/1440px 列表无横向溢出；390px 编辑页单列，保留四项底部导航；桌面/手机截图已实际打开查看。
