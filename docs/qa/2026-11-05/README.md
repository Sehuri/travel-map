# 下一站去哪：随机推荐与指定城市

验收日期：2026-11-05。验收在本地完成；未修改数据库、权限、密钥、服务端接口或配额。代码提交及推送状态以 Git 历史为准。

## 已实现

- 新增“随机推荐 / 指定城市”切换；沿用白蓝控件、现有城市目录与地图。
- 随机模式保留完整出发地、1–14 天、范围、预算、省份、已去过排除、偏好、候选去重与比较。
- 指定模式通过目录的完整行政归属匹配城市 ID，跳过抽签与候选比较。不会因随机模式的旧距离、预算、省份、已去过设置而阻止明确选城。
- 指定模式出发地可空；为空时不请求路线，不显示虚构交通或总预算。填写后复用实际路线和估算降级；同城探索不请求城际路线。
- 共用景点 / 美食分类、真实地图和外链、每日攻略、日期与地图联动、愿望去重保存、复制及手动复制降级。
- 加载时锁定选城与模式开关，失败可重试；条件改动后不会以旧条件重试。返回上次目的地保留资源及已生成攻略，不重新请求资源。
- 两种模式保留输入；旧结果会明确提示。键盘输入顺序与模式对应的视觉布局保持一致。

## 主要文件

- `discover.html`：双模式入口、选城表单、错误重试与资源版本。
- `assets/discover.js`：模式状态、验证、请求、结果恢复、分享与保存。
- `assets/discover-engine.js`：目录 ID 直选与可选出发地的规划元数据。
- `assets/discover.css`：仅限随机旅行页的控件与响应式布局。
- `tests/discover-city-browser.cjs`：新增端到端测试；`tests/discover.test.cjs`、`tests/discover-blue.test.cjs` 补充逻辑与结构回归。
- `package.json`：将指定城市测试加入完整检查；项目 `README.md` 更新功能说明。

## 保留的限制

- 目的地范围沿用现有全国目录；接口不可用时只能选择明确标注的 18 城示例，不支持任意输入目录外城市或海外城市。
- 攻略仍是按已有点位、直线距离与节奏生成的未核验草案，不是导航或已验证行程。
- 资源依赖现有接口；失败可重试，地图失败仍保留文字列表和外链。保存愿望仍为当前浏览器本地保存，不是云端同步。
