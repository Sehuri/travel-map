# 🗺️ Sehuri 的旅行足迹

一个用地图与时间记录旅程的个人旅行网站。

从 2013 年黄海边的第一次远行，到 2026 年绍兴初夏的水乡漫步；这里收藏走过的城市、拍下的风景，以及仍在期待的下一站。

## 🌏 在线访问

**[打开旅行足迹地图](https://sehuri.github.io/travel-map/)**

## ✨ 网站功能

### 下一站去哪（全国城市推荐）

- 新增独立随机旅行页面，可选择出发地、游玩天数、距离、省份和旅行喜好。
- 全国模式按行政编码收录地级市、直辖市和县级市，不局限现有旅行记录；实际范围以高德目录为准，台湾城市暂待补充。
- 结果包含城市概览、旅游资源列表和地图；全国服务已启用，连接异常时会明确提示，并提供可选的 18 城示例体验。
- 服务端 Key 不进入公开仓库，查询有每日预算保护。启用步骤见 [DISCOVER_SETUP.md](./DISCOVER_SETUP.md)。

### 高德旅行地图

- 地图统一使用高德 JS API 2.0，不再区分世界和中国，也不再加载第三方世界底图。
- 仅中国大陆坐标在地图层转换为 GCJ-02；日本、韩国、台湾、香港和澳门保持原始 WGS-84 坐标。高德安全密钥由 Supabase 代理保护，启用步骤见 [AMAP_MAP_SETUP.md](./AMAP_MAP_SETUP.md)。
- 国内足迹按市级行政区填色，大阪、京都、东京和镰仓以带名称的城市光点呈现
- 点击已到访市域或城市光点即可打开对应旅行记忆
- 切换到“仍在期待”时，地图同步改为展示 22 个愿望目的地，点击光点可查看旅行攻略
- 高德资源不可用时会明确提示，下方时间线仍可继续浏览

### 旅行数据统计

网站会根据旅行记录自动展示：

- 已到访城市数量
- 已覆盖国家数量
- 持续旅行的年份数量
- 根据城市经纬度自动计算最北、最南、最东和最西足迹，并可点击查看城市详情

当前已记录 **52 座城市、2 个国家、5 个旅行年份**。

### 年度旅行时间线

- 按年份整理所有到访城市
- 支持按城市名称搜索，并按年份、国家或地区、社区评分组合筛选
- 筛选结果会同步更新地图标记、视野、统计数字和四方足迹，并支持一键清除筛选
- 以路线节点串联各年份，并展示全旅程序号、到访日期、所在国家和经纬度
- 增加罗盘、地图网格与等高线纹理，让时间线同时具有旅行地图和航行日志的视觉感受
- 城市卡片展示平均分与评分人数，并提供实时更新的城市评分排行榜
- 点击城市卡片可查看详细旅行介绍
- 每座城市拥有 `?city=城市名` 独立链接，并支持复制或系统分享

### 城市资料与公众评分

- 站主可通过邮箱登录，直接在城市详情中填写最喜欢的地点、吃过的食物和适合旅行天数
- 访客可对每座城市提交 1—10 分评分，并随时修改自己的评分
- 页面自动计算并显示平均分和评分人数
- 数据由 Supabase 保存，并通过行级安全策略限制编辑权限

首次启用资料与评分功能前，请按 [Supabase 配置说明](./SUPABASE_SETUP.md) 完成数据库与前端连接。

### 站主管理后台

- 站主通过邮箱登录 [`admin.html`](./admin.html)
- 可添加城市，修改日期、国家、地区、坐标和描述
- 可上传和排序照片，并指定城市封面图
- 可新增、编辑、排序或隐藏愿望清单项目，并设置计划去的时间
- 可查看并删除明显异常的公众评分，平均分会自动重算
- 采用“Supabase 后台内容优先、代码资料兜底”的方式，仍可继续直接修改代码维护

启用后台前需要额外运行 [`supabase/admin_backend.sql`](./supabase/admin_backend.sql)，具体步骤见 [Supabase 配置说明](./SUPABASE_SETUP.md)。

### 城市照片画廊

- 在城市详情中浏览真实旅行照片
- 支持缩略图展示和大图预览
- 照片按城市分类保存
- 当前收录东京、京都、北京、大阪、苏州、镰仓、阿拉善盟和黄山等城市的旅行影像

### 下一站愿望清单

- 在首页首屏通过“旅行足迹 / 仍在期待”TAB 直接切换，无需滚动到页面底部
- 收藏未来想去的目的地
- 下方地图会同步切换为愿望目的地视图，不再继续显示已到访城市
- 提供“在地图上查看”快捷入口，手机端无需越过全部愿望卡片
- 展示目的地特色、计划时间与简要旅行建议
- 可跳转至常用旅行平台继续查看攻略

愿望目的地包括印度尼西亚的布罗莫火山与雅加达、新加坡、伊犁与赛里木湖、台湾本岛、大理丽江香格里拉、川西、乌兰布统、广州、澳门、成都、重庆、张家界、恒山、雁荡山、釜山、长白山、黄果树瀑布、天柱山、萨武神山、黑独山、敦煌与峨眉山。

### 响应式体验

- 适配电脑、平板和手机
- 手机端提供首页、地图、足迹和愿望底部快捷导航，旅行年份可折叠
- 支持键盘操作与语义化对话框
- 支持系统“减少动态效果”偏好
- 高德地图采用浅色标准底图，以青蓝色行政区块标记国内足迹，并用带名称的城市光点标记大阪、京都、东京和镰仓

## 🎨 设计理念

网站以“个人旅行档案”为视觉方向：

- 深夜蓝象征地图与远方
- 首页使用大阪环球影城马里奥园区实拍照片铺满整个首屏，以天空蓝与园区绿作为主要底色，并只在文字区域增加轻量遮罩
- 地图、旅行足迹和评分排行延续同一张照片背景，通过半透明蓝绿色内容层形成连续的整站视觉
- 主要信息卡片采用天空蓝与青绿色磨砂玻璃效果，减少深黑色块对照片背景的割裂感
- 荧光绿色作为旅途坐标和互动提示
- 大字号衬线标题强化旅行杂志感
- 时间线负责回望过去，愿望清单指向下一次出发

## 🚀 维护与发布

提交前可重复执行完整测试：

```bash
npm ci
npx playwright install chromium
npm test
```

其中 `npm test` 会依次运行数据与地图单元测试、首页筛选及手机端浏览器测试、随机旅行浏览器测试。推送或创建 Pull Request 时，GitHub Actions 会自动执行同一套检查。

正式 Git 工作目录：

```text
/Users/macbook/Desktop/个人文件/个人文件/travel-map
```

日常发布流程：

```bash
git status
git diff
git add <本次修改的文件>
git commit -m "说明本次修改"
git push origin main
```

推送到 `main` 后，GitHub Pages 会自动更新；提交前应确认没有夹带与本次功能无关的文件。

## 📍 关于这个项目

旅行结束以后，车票会遗失，相册会越积越多，而地图能让不同年份的记忆重新产生联系。

这个网站会随着新的旅程持续更新。每增加一座城市，地图上就会多一个光点，时间线上也会多一段属于那一天的记录。
