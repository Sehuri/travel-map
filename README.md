# 🗺️ Sehuri 的旅行足迹

一个用地图与时间记录旅程的个人旅行网站。

从 2013 年黄海边的第一次远行，到 2026 年绍兴初夏的水乡漫步；这里收藏走过的城市、拍下的风景，以及仍在期待的下一站。

## 🌏 在线访问

**[打开旅行足迹地图](https://sehuri.github.io/travel-map/)**

## ✨ 网站功能

### 世界与中国双地图

- 在互动地图上查看所有到访城市
- 支持“世界”和“中国”两种地图范围
- 点击地图光点即可打开对应城市的旅行记忆
- 中国与海外城市可以在同一段旅程中完整呈现

### 旅行数据统计

网站会根据旅行记录自动展示：

- 已到访城市数量
- 已覆盖国家数量
- 持续旅行的年份数量

当前已记录 **52 座城市、2 个国家、5 个旅行年份**。

### 年度旅行时间线

- 按年份整理所有到访城市
- 支持选择年份快速筛选
- 展示城市、到访日期和所在国家
- 点击城市卡片可查看详细旅行介绍

### 城市照片画廊

- 在城市详情中浏览真实旅行照片
- 支持缩略图展示和大图预览
- 照片按城市分类保存
- 当前收录东京、京都、北京、大阪、苏州、镰仓、阿拉善盟和黄山等城市的旅行影像

### 下一站愿望清单

- 收藏未来想去的目的地
- 展示目的地特色与简要旅行建议
- 可跳转至常用旅行平台继续查看攻略

愿望目的地包括印度尼西亚的布罗莫火山与雅加达、新加坡、伊犁与赛里木湖、台湾本岛、大理丽江香格里拉、川西、乌兰布统、广州、澳门、成都重庆、张家界、恒山与雁荡山。

### 响应式体验

- 适配电脑、平板和手机
- 支持键盘操作与语义化对话框
- 支持系统“减少动态效果”偏好
- 深色地图与旅行档案风格贯穿整个页面

## 🎨 设计理念

网站以“个人旅行档案”为视觉方向：

- 深夜蓝象征地图与远方
- 荧光绿色作为旅途坐标和互动提示
- 大字号衬线标题强化旅行杂志感
- 时间线负责回望过去，愿望清单指向下一次出发

> 世界很大，我用足迹丈量。

## 🛠️ 技术实现

- 原生 HTML、CSS 与 JavaScript
- Leaflet 互动地图
- OpenStreetMap 与 CARTO 地图图层
- GitHub Pages 静态部署
- 本地旅行数据与照片资源

## 📍 关于这个项目

旅行结束以后，车票会遗失，相册会越积越多，而地图能让不同年份的记忆重新产生联系。

这个网站会随着新的旅程持续更新。每增加一座城市，地图上就会多一个光点，时间线上也会多一段属于那一天的记录。
